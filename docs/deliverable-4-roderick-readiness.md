# Deliverable 4 — Roderick Contribution

## Release-readiness review checklist

This checklist was added to support the Deliverable 4 QA and release-readiness work.

| Area | Verification |
|---|---|
| Automated tests | Confirm the current local test suite result before presenting it as evidence. |
| QA evidence | Keep manual QA results tied to actual reproduction steps and observations. |
| Bug triage | Record confirmed issues with reproduction steps, expected result, actual result, and severity. |
| Environment safety | Keep production secrets out of the repository and use environment variables for deployment configuration. |
| Deployment | Record the real public URL only after deployment is actually completed. |
| Smoke test | Verify login, a representative CRUD flow, and one validation/failure path in the deployed environment. |
| Presentation | Prepare the demo flow and a backup screenshot/video set before the presentation. |

## Status rule

A checklist item should be marked complete only when it has been actually verified. Public deployment and live smoke tests remain pending when the application is only available locally.
