# Week 12 — Demo Rehearsal Checklist

## Required demo arc

Problem → Solution → Architecture → Live Demo → What We Learned

## Click path

1. Login.
2. Open Dashboard.
3. Open Products.
4. Show a product record.
5. Show Supplier or Category management.
6. Show an inventory workflow or POS.
7. Open Reports or Audit Trail.
8. Demonstrate one graceful validation failure.

## Rehearsal checks

- [ ] Exact click path completed once from start to finish.
- [ ] Presentation fits the assigned time.
- [ ] Each member knows their presentation section.
- [ ] One validation/failure case is ready.
- [ ] Backup screenshots/video are prepared.
- [ ] Live deployment URL is available before claiming the demo as complete.
