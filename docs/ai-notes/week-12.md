# Week 12 — AI Use Record

## Oral-defense restriction

The Week 12 handout explicitly states that AI is off for the oral defense. This document records preparation assistance only; it must not be used as AI assistance during the actual individual defense.

## Preparation prompts used

### Retrospective
> Draft a blameless retrospective for the inventory management project using only documented development outcomes. Include what went well, what did not go as planned, what we would change, and concrete lessons. Do not claim deployment or tests that were not actually completed.

### Defense preparation
> Create a list of technical concepts and questions a student should be able to explain from their own Laravel inventory-management code: request flow, authentication, validation, missing records, errors, tests, and bug fixes. Make it preparation material, not answers to be used during the oral defense.

### Demo rehearsal
> Create a concise rehearsal checklist following the Week 12 arc: problem, solution, architecture, demo, lessons learned. Include one graceful validation failure and a backup plan.

## Human responsibility

Each member must understand and explain their own code independently during the actual defense.
